# 對坐象棋

手機直式網頁象棋＋暗棋＋西洋棋＋五子棋＋9×9 圍棋，單一檔案 `index.html`，可直接放上 GitHub Pages。選單上方切換「象棋／暗棋／西洋棋／五子棋／圍棋」，單機、AI、連線三種對戰方式都能用。

暗棋規則（台灣半盤）：4×8 棋盤、32 子全蓋；第一顆翻開的顏色就是翻棋者的顏色。每步可翻一顆棋或把己方棋子走一格；帥＞仕＞相＞俥＞傌＞炮＞兵，大吃小、同級互吃，兵可吃帥、帥不能吃兵；炮須隔一子跳吃（不限距離、可吃任何棋）。吃光對方或對方無棋可走即獲勝，連續 60 步沒有吃子或翻棋判和。另有**連吃**（吃子後同一顆棋可繼續吃，或按「停手」）與**探草**（用已翻開的棋去碰蓋著的棋：翻開後吃得到就吃，吃不到就留在原地）。

西洋棋採標準規則：入堡、吃過路兵、升變（可選后／車／象／馬），將死、逼和、50 步規則、三次重複、子力不足判和。

象棋禁止長將：一路將軍又讓同一局面第三次出現的那一步不能走。

五子棋：15×15、黑先、連成五子以上獲勝（不設禁手）。點一下預覽、再點同一格落子；對手只差一子就連成五時，那幾顆棋會閃紅光。

圍棋 9×9：中國數子法、貼 6.5 目，禁止自殺與全局同形（打劫）。可「虛手」，雙方連續虛手進入數子：AI 先估死子，可點棋塊修正後「確認計分」，或「繼續下」。只剩一口氣的棋會閃紅光，下了會只剩一口氣的預覽顯示紅框。

象棋外觀設定（選單的「象棋外觀設定」）：上方是依目前設定畫出的整盤預覽，下面分「紅方棋子／黑方棋子／棋盤」三頁，紅黑各自選字體（19 種，含小篆、隸書與多款歌德體）、字色（19 種）、棋子材質（19 種），棋盤材質 18 種。會讓字看不清、棋子和棋盤混色、或紅黑分不出的組合會灰掉不能選。

字形來源：小篆取自[開元小篆 Kaiyuan Small Seal Font](https://github.com/frankslin/kaiyuan-small-seal-font)（SIL OFL 1.1），隸書取自 [hanzi-glyphs-svg](https://github.com/zhouyongh/hanzi-glyphs-svg) 隸書層（CC0 1.0），皆描摹自《說文解字》與漢代碑簡；俥、傌、砲等古代沒有的字以部件組合。其餘字體由 Google Fonts 載入。

資訊列的「!」開關紅色警示（含走過去會被吃的格子標紅），「AI」開關 AI 提示（以 Lv 4 計算，推薦走法標綠）。

- **單機對戰**：同一台手機或電腦，兩人輪流下。選單的「單機面對面」開啟時黑方畫面倒轉，適合手機平放面對面；手機預設開、電腦預設關。
- **和 AI 對戰**：滑動條 Lv 1–10 調整強度，運算在玩家自己的手機上進行。
- **連線對戰**：創建房間取得 4 位數房號，朋友輸入房號加入。房主先手（象棋執紅、西洋棋執白、五子棋與圍棋執黑）並負責判定棋步，連線透過 PeerJS 點對點傳輸。
